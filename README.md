# Generic TypeScript Project

This repository is a generic TypeScript project designed for testing TypeScript features and practicing interview questions.

## Usage

- Experiment with TypeScript syntax and features.
- Practice solving TypeScript interview problems.
- Use as a template for TypeScript exercises.

## Getting Started

1. Clone the repository.
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start coding!

## Folder Structure

- `src/` — Place your TypeScript files here.
- `tests/` — Add test files for your solutions.
